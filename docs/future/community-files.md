# Repository extras for contributors

**Status**: deferred on 2026-10-22, when the repository's protections went in. Nothing here is built yet.

**Already in place**:

- **`main`**: protected by a ruleset. Pull requests need CI on Linux and macOS and the code owner's review, and are squash-merged.
- **Release tags**: `v*` tags are protected.
- **Security**: Dependabot alerts and security updates, secret scanning with push protection, and private vulnerability reporting.
- **Outside contributors**: their workflow runs need approval.
- **Files**: `SECURITY.md`, `CONTRIBUTING.md` and `.github/CODEOWNERS`.

These three extras were left for later.

## Dependabot version updates

**What**: a `.github/dependabot.yml` that opens weekly pull requests updating Cargo crates and the GitHub Actions the workflows use. Security updates already arrive without it.

**Notes**:

- Group the updates (one pull request for Cargo patches and minors, one for Actions) so they don't swamp the queue.
- `alacritty_terminal`, `ratatui` and `crossterm` have changed rendering before, so check their updates against the UI snapshots.
- `.github/workflows/release.yml` is generated by `dist`. Update it through `dist`, not by hand or with Dependabot: ignore `release.yml` there, or regenerate it after an Actions bump.

## Issue and pull request templates

**What**:

- `.github/ISSUE_TEMPLATE/`: issue forms for bug reports and feature requests. Bug reports ask for the version, the OS, the agent, the steps, and `daemon.log` lines if any.
- A `config.yml` there that points security reports to private reporting and questions elsewhere.
- `.github/pull_request_template.md`: a short checklist (fmt, clippy, `scripts/test.sh`, docs updated, fixtures blessed on purpose).

**Notes**: keep the forms short. Ask for what [CONTRIBUTING.md](../../CONTRIBUTING.md) already asks for, not more.

## Code of conduct

**What**: `CODE_OF_CONDUCT.md` with the Contributor Covenant (2.1), linked from `CONTRIBUTING.md`, plus a contact address for reports.

**Notes**: it needs a reporting contact that isn't a public issue. Decide which address to publish before adding it.
